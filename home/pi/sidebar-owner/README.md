# sidebar-owner

Home Manager-managed fork of [`pi-sidebar-tui` 1.5.2](https://github.com/bi0h4z4rd88/pi-sidebar-tui).

It owns Pi's footer/sidebar UI, reads the real `@juicesharp/rpiv-todo` snapshots,
and suppresses duplicate rpiv-todo and pi-lens widgets. The Activity panel shows
active tool names and the pi-lens error total; `/errors` prints errors grouped by
file. See `LICENSE` for the upstream license.
